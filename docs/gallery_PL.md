# Galeria produktu

Zrzuty pokazują wybrane funkcje lokalnego panelu WWW T-REX HOME. Są wyłącznie
materiałem dokumentacyjnym: publiczne repozytorium nie zawiera firmware ani
kodu źródłowego sterownika.

Galeria celowo nie zawiera ekranów z rzeczywistymi adresami lokalnymi, nazwami
sieci Wi-Fi, adresami stacji pogodowych ani identyfikatorami odbiorników rolet.

## Dashboard HOME

![Dashboard T-REX HOME](../images/home-dashboard.png)

Dashboard łączy kontekst fasad, lokalne dane pogodowe i szybkie akcje.

## Konfiguracja rolet i scen

![Dodawanie rolety oraz wybór ściany](../images/home-add-roller-wall-picker.png)

Przypisanie rolety do ściany jest elementem konfiguracji i nie zależy od
kierunku geograficznego.

![Sceny](../images/home-scenes.png)

Sceny umożliwiają użytkownikowi ustawienie własnych akcji ON i OFF dla
wybranych rolet.

## Nawigacja i planowane moduły

![Nawigacja](../images/home-navigation-menu.png)

Menu grupuje widoki lokalnego sterowania, pogody, scen i konfiguracji.

![Placeholder bramy](../images/home-gate-placeholder.png)

Sterowanie bramą jest pokazane jako planowany obszar interfejsu; jego backend
nie jest częścią publicznej dokumentacji.

![O T-REX HOME](../images/home-about.png)

Widok „O programie” przedstawia zasadę local-first oraz kontakt techniczny.
